# Soft3TT Conversion API

Independent backend for `soft3tt.online`. It accepts multipart uploads and performs server-side conversions with FFmpeg, ImageMagick and LibreOffice.

## Current tools

- mov-to-mp4
- mp4-to-webm
- video-to-mp3
- mp4-to-mp3
- wav-to-mp3
- m4a-to-mp3
- video-to-gif
- jpg-to-png
- png-to-jpg
- webp-to-jpg
- heic-to-jpg
- jpg-to-pdf
- pdf-to-jpg
- word-to-pdf

`pdf-to-word` is intentionally listed by the API but disabled until a dedicated PDF/OCR conversion pipeline is added.

## API

### Health
`GET /api/health`

### Tools
`GET /api/tools`

### Convert
`POST /api/convert`

Multipart fields:

- `file`: uploaded file
- `tool`: conversion tool ID
- `quality`: optional video quality such as `original`, `1080`, `720`, `480`
- `audio`: optional audio bitrate such as `original`, `128`, `192`, `256`

Response:

```json
{
  "ok": true,
  "jobId": "...",
  "tool": "mov-to-mp4",
  "downloadUrl": "https://api.soft3tt.online/api/download/...",
  "filename": "Soft3TT-mov-to-mp4.mp4",
  "expiresInMinutes": 60
}
```

### Download
`GET /api/download/:jobId`

Converted files are stored temporarily and cleaned automatically after the configured TTL.

## Local development

Requirements: Node.js 20+, FFmpeg, ImageMagick and LibreOffice.

```bash
npm install
cp .env.example .env
npm start
```

Health check:

```bash
curl http://localhost:8080/api/health
```

Test conversion:

```bash
curl -F "file=@sample.mov" -F "tool=mov-to-mp4" http://localhost:8080/api/convert
```

## Deployment

The included Dockerfile is the preferred deployment method because the backend needs native conversion programs. Render can deploy the Docker service using `render.yaml`. Set `PUBLIC_BASE_URL` to the public API URL assigned to the service, then point the Soft3TT Blogger interface at that URL.

## Security notes

- Uploads have a configurable maximum size.
- Only one file is accepted per conversion request.
- Tool IDs are allowlisted; arbitrary shell commands are never accepted from users.
- Input and output names are generated by the server.
- Download job IDs are random UUIDs.
- Temporary jobs are automatically deleted.
- CORS is restricted to the Soft3TT domains by default.
- Do not expose private credentials in the Blogger theme.
- For production, add malware scanning, rate limiting, authentication/quotas and persistent object storage before accepting high-volume traffic.
